# UniWorks
# 🤖 UniWorks — Telegram-бот для купівлі та продажу студентських робіт

**UniWorks** — це Telegram-маркетплейс, який дозволяє студентам купувати та продавати приклади академічних робіт. Бот автоматизує публікацію, пошук, рейтинг та інші функції, щоб зробити обмін знаннями зручним і безпечним.

## 🔍 Основні можливості (в розробці)

- Публікація робіт з метаданими (факультет, дисципліна, оцінка, ціна)
- Каталог з фільтрами, сортуванням і пошуком
- Вбудований рейтинг продавців
- Захист від плагіату: `ssdeep` + watermark UUID
- Перевірка дублікатів і антивірус-сканування
- Щоденні дайджести нових робіт
- Модерація спорів і дублікатів (адмін-бот)

> 💸 Інтеграція з оплатами та ескроу ще **в розробці**
